aws ke andar vcp hota h 
vcp => virtual private cloud 

vcp ke andar subnet hota h 
subnet 2 type ke hote :
1. Public subnet => accepts traffic from internet 
2. private subnet => accepts traffic from elements only inside the vcp

public subnet me server ko rakhte h 
private subnet me database ko rakhte h

AWS ke andar Do chije or bhi hoti  hai 
1. ECR => Elastic container registry
1. ECS => Elastic container Service


ECR used to store docker images 

ECS docker file ko run krta hai jo ECR me store hoti hai 

ECS ke andar task or services hote hai

Tasks decide krta hai konsi image select karni h or konsi machine pe run karna h 

Service hamare actual server ko run karti hai 

jab  bhot sari same requests hoti hai to services unhe parallely run karta hai

services request ko server pe bhejta hai usse pehle  ek ALB aata hai (Automatic load balancer)

jo traffic internet se aata hai usko ALB decide karta hai kosni service use krega ,then server pe pass krega 

ALB or services ke beech me Target Group (TG) bhi aata h 

Target group decide krega traffic kaha pe jane wala hai 

Ek chij or hoti hai Security group ,
SG define karta hai ap konse port se request kr skte ho or response konse port se ayega
